# Quiz Assister for Binogi

Browser extension designed to assist with quizzes on Binogi with a clean, minimal user interface.

## Features
* Clean and simple graphical user interface.
* Fast performance using Manifest V3.
* Toggleable on/off switch in a popup gui.
  
---

## Privacy Policy

**Effective Date:** August 27, 2026

**Quiz Assister for Binogi** respects your privacy. This policy details how user data is handled:

* **Data Collection:** This extension does **not** collect, track, store, or transmit any personal identifiable information (PII), browsing history, or analytics data.
* **Local Storage:** Any temporary configuration, user options, or settings stored by the extension remain strictly local to your browser using the `chrome.storage` API and are never uploaded to remote servers.
* **Network Activity:** The extension does not communicate with external servers or third-party APIs. All processing runs entirely on the user's local client.
* **Third-Party Sharing:** No data is shared with or sold to third parties under any circumstances.
